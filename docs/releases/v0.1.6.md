# GitCloneGui v0.1.6

这个版本重新整理了应用的整体视觉层级，让它更像一款克制、耐用的桌面工具，同时保留现有仓库克隆、工作区扫描、分支搜索和切换流程。

## 主要更新

- 左侧导航改为窄幅中性侧栏，当前页面使用浅色底和细指示条，不再使用大面积高饱和蓝色。
- 两个页面统一为低饱和中性色、小圆角和更紧凑的 4/8/12/16 间距，减少重复卡片嵌套与无效留白。
- 收紧标题、状态、数量标识、表单和列表的视觉层级，提高同屏信息密度。
- `BranchSelector` 与仓库树同步新的中性/强调色，保留原有圆角、行高和交互命中范围。
- 侧栏左上角不再使用蓝色方块字母 `G`，改为跨平台一致的 Git 分支节点矢量图标，在 Retina/高 DPI 屏幕上保持清晰。

## 功能保持

- 仓库克隆、配置恢复、Git 实时输出、取消和完成通知行为保持不变。
- 工作区递归扫描、工作树风险提示、本地/远端待跟踪分支和有限错字搜索保持不变。
- 本次不改变 Git 命令、配置格式、应用 Bundle 图标、部署结构或签名流程。

## 下载

- `GitCloneGui-macOS-arm64.dmg`：Apple Silicon Mac。
- `GitCloneGui-Windows-x64.zip`：64 位 Windows 10/11 便携包。

运行应用需要本机已安装 Git，并可从 `PATH` 调用 `git`。

## 签名提示

如果仓库未配置 Developer ID、公证或 Authenticode Secrets，流水线仍会生成经过结构验证的测试包，但 macOS 可能要求在“系统设置 → 隐私与安全性”中确认“仍要打开”，Windows SmartScreen 也可能提示未知发布者。这不等同于已签名或已公证的正式分发包。
