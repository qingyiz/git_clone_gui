# GitCloneGui v0.1.4

这个版本加入了全新的“仓库工作区”，适合在一个包含多个独立项目和嵌套项目的工作目录中，集中查看仓库与切换分支。

## 主要更新

- 新增左侧导航，可在“仓库克隆”和“仓库工作区”之间切换，并在重启后恢复上次页面。
- 递归发现工作目录中的 Git 仓库，支持嵌套仓库以及 `.git` 为文件的 worktree/submodule 形态。
- 使用重新设计的仓库树展示目录层级、文件夹与仓库图标，统一展开、选中和滚动视觉。
- 选中仓库后显示当前分支、本地分支、远端待跟踪分支和全部远端跟踪分支，可快速执行本地或远端跟踪分支切换。
- 工作目录会自动保存；再次启动时恢复有效目录并在后台自动扫描。
- 分支详情会实时检查工作树。存在已暂存、未暂存、未跟踪或冲突项时，会显示醒目的谨慎切换提示和分类数量。
- Git clone 继续支持实时传输进度和任务总耗时。

## 扫描性能

扫描器减少了逐目录 canonical 路径解析和不必要的文件元数据开销。在开发机约 57,327 个目录、17 个仓库的工作区中，三次扫描中位数由约 18.019 秒降至约 5.052 秒，结果数量保持一致；实际速度仍会受到磁盘、目录规模和权限影响。

## 分支切换说明

- 远端待跟踪列表只显示本地尚无同名分支的 remote-tracking refs。
- 应用不会自动执行 `fetch`、`stash`、`reset` 或 `clean`。
- 工作树有改动时不会强制禁止切换，但请先确认改动安全；如果 Git 判断切换会覆盖文件，操作会失败并显示原始错误。

## 下载

- `GitCloneGui-macOS-arm64.dmg`：Apple Silicon Mac。
- `GitCloneGui-Windows-x64.zip`：64 位 Windows 10/11 便携包。

运行应用需要本机已安装 Git，并可从 `PATH` 调用 `git`。

## 签名提示

如果仓库未配置 Developer ID、公证或 Authenticode Secrets，本次流水线仍会生成经过结构验证的测试包，但 macOS 可能要求在“系统设置 → 隐私与安全性”中确认“仍要打开”，Windows SmartScreen 也可能提示未知发布者。这不等同于已签名或已公证的正式分发包。
