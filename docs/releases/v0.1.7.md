# GitCloneGui v0.1.7

这个版本修正工作区分支搜索和远程分支加载的两个实际使用问题。

## 主要修复

- 移除 v0.1.5 引入的错字容错模糊搜索。现在只执行 trim 后、大小写不敏感的包含搜索，搜索结果更直接、可预期。
- 修复远程分支列表不全。选中仓库或点击刷新时，应用会枚举全部 remote，并对每个 remote 显式抓取所有 `refs/heads/*`。
- 即使本地仓库来自 single-branch clone，或原有 fetch refspec 只覆盖少数分支，远程待跟踪列表也会加载服务器上的全部 heads。
- 刷新同时执行 prune，服务器上已删除的分支不会继续残留在候选列表。

## 安全与行为边界

- fetch 只更新 remote-tracking refs，不修改工作树文件、索引或当前 HEAD。
- 应用不会自动执行 pull、push、merge、reset、stash 或 clean。
- fetch 禁用交互式凭据提示。认证未配置、网络失败或超时时，页面保留现有结果并显示 Git 诊断信息。

## 验证

- 自动化测试覆盖纯包含搜索、错字不命中和本地/远程各 1,000 个分支的筛选。
- 真实 Git 集成测试故意把 consumer refspec 限制为只抓取 `main`，仍验证远程新分支可见、删除后可被 prune。

## 下载

- `GitCloneGui-macOS-arm64.dmg`：Apple Silicon Mac。
- `GitCloneGui-Windows-x64.zip`：64 位 Windows 10/11 便携包。

运行应用需要本机已安装 Git，并可从 `PATH` 调用 `git`。
