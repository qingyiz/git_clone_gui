# GitCloneGui v0.1.5

这个版本重点优化了仓库工作区中的分支查找体验。面对数百甚至上千个分支时，可以直接搜索；即使少输、多输、输错字母或把相邻字母写反，也能找到接近的分支。

## 主要更新

- 分支详情移除没有切换操作的“全部远端”页签，只保留“本地分支”和“远端待跟踪”两个可操作列表。
- 新增共享分支搜索框，可同时筛选两个列表，搜索过程不访问 Git 或网络。
- 精确包含匹配优先，并且不区分大小写、忽略搜索词首尾空格。
- 输入至少 3 个字符后启用有限模糊匹配，支持漏字、多字、错字和相邻字母颠倒。
- 搜索词越长，可容忍的错误越多：3～4 个字符最多 1 处，5～8 个字符最多 2 处，9 个及以上最多 3 处；1～2 个字符保持精确，避免短词产生过多误匹配。
- 清空搜索即可恢复完整列表；筛选结果为空或当前选择被隐藏时，切换按钮会自动禁用。

## 性能与安全边界

- 自动化测试覆盖本地与远端各 1,000 个分支的错字搜索，并要求单次更新不超过 250ms。
- 搜索只在已加载的分支名上执行，不会触发 `fetch`、读取远端或额外运行 Git 命令。
- 分支切换仍沿用原有安全行为：应用不会自动执行 `stash`、`reset`、`clean`、`pull` 或 `fetch`，工作树有改动时请先确认改动可以安全带入目标分支。

## 下载

- `GitCloneGui-macOS-arm64.dmg`：Apple Silicon Mac。
- `GitCloneGui-Windows-x64.zip`：64 位 Windows 10/11 便携包。

运行应用需要本机已安装 Git，并可从 `PATH` 调用 `git`。

## 签名提示

如果仓库未配置 Developer ID、公证或 Authenticode Secrets，本次流水线仍会生成经过结构验证的测试包，但 macOS 可能要求在“系统设置 → 隐私与安全性”中确认“仍要打开”，Windows SmartScreen 也可能提示未知发布者。这不等同于已签名或已公证的正式分发包。
